🔨 BUILD COMMANDS

  Windows (Visual Studio):
    cd Win32Version
    build.bat

  Manual build:
    cd Win32Version
    mkdir build
    cd build
    cmake .. -G "Visual Studio 17 2022" -A x64
    cmake --build . --config Release

  Run:
    cd build\bin\Release
    JustASample_Win32.exe
